# Code of Conduct

## Our Pledge

We are committed to keeping Peel UI a welcoming, respectful, and high-craft open-source community for everyone. Whether you are reporting a bug, proposing a new interaction primitive, or discussing spring physics, we expect participants to treat each other with respect.

## Expected Behavior

- **Focus on the craft:** Keep critiques focused on code, motion mechanics, accessibility, and UI architecture—never on the person.
- **Be constructive and specific:** When reporting bugs or suggesting improvements, include clear reproduction steps, browser/OS details, or visual recordings.
- **Respect maintainer scope:** Peel UI is an opinionated library with a strict visual and performance bar. Not every feature request or component style will fit the registry, and maintainer decisions on scope are final.

## Unacceptable Behavior

- Harassment, personal attacks, insults, or derogatory comments of any kind.
- Spamming pull requests (such as automated typo fixes or empty edits) solely to farm GitHub contribution graphs.
- Publishing others' private information without explicit permission.
- Any other conduct that could reasonably be considered inappropriate in a professional open-source environment.
